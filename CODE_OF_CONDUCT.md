# Code of Conduct

## Our pledge

We want netcafe-guard to be a welcoming place to contribute, regardless of
experience level, background, or identity. First-time contributors are
especially welcome — most rule contributions need no prior open-source
experience.

## Expected behaviour

- Be respectful and constructive. Assume good faith.
- Keep discussion focused on defensive security. This project is for protecting
  shared PCs, not attacking them.
- Give credit; help newcomers land their first PR.

## Unacceptable behaviour

- Harassment, personal attacks, or discriminatory language.
- Using the project to develop or share offensive tooling, or to help
  compromise machines you are not authorised to secure.

## Enforcement

Maintainers may edit, remove, or reject contributions and comments that violate
this code, and may block repeat offenders. Report concerns by opening a private
security advisory or contacting the maintainer via their GitHub profile.

Adapted from the [Contributor Covenant](https://www.contributor-covenant.org/),
version 2.1.
